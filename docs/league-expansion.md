# League expansion review — 7 November 2026

Added Championship (ELC), Eredivisie (DED) and Primeira Liga (PPL), season2026.
Champions League is deliberately excluded. The provider roster snapshot has24,
18 and18 clubs respectively. Names and provider IDs are contracted explicitly.

This is a current canonical-home-ground registry for upcoming draws, not a claim
that historical matches were played at their clubs’ present ground. Finished
matches remain outside the eligible draw pool. Estrela’s20September2026 match
was temporarily moved to Rio Maior following a turf restriction; its current
November listings confirm José Gomes again. See the [club statement](https://estrelamadora.pt/comunicado-oficial-16set/).

Stale provider venue names and office/postal addresses are not automatically
approved. The destination city is reviewed explicitly. Optional physical street
addresses are omitted when not verified. For unchanged obvious English grounds,
the API stadium/address record corroborates the locality; corrections and the
Dutch/Portuguese grounds have additional primary sources below. The provider
`sourceUrl` remains stable, while `verificationUrl` records the corroboration;
seeding uses the latter as database provenance when available.

Welsh Championship grounds use Wales rather than the league’s England label.
An England competition flag is omitted for such destinations. Country beer data
is optional and never borrowed from the competition’s country. Portugal’s island
clubs use Atlantic/Madeira or Atlantic/Azores; mainland clubs use Europe/Lisbon.

## Scoped operation and verification

The reviewed roster contract is for season 2026. Other seasons, partial rosters, changed names and foreign competition members fail before fixture writes. Imports pace provider requests at least seven seconds apart.

```sh
npm run fixtures:sync:preflight -- 2026 ELC,DED,PPL
npm run venues:seed -- ELC,DED,PPL
npm run fixtures:sync -- 2026 ELC,DED,PPL
```

On 7 November 2026 the scoped seed upserted 60 reviewed venues and the fixture transaction upserted 1,164 fixtures: ELC 552, DED 306, PPL 306. Future confirmed fixtures linked to active reviewed venues numbered ELC 383, DED 206 and PPL 215 at verification time. These counts change with time and provider updates. Existing five league totals remained unchanged: BL1 307, FL1 307, PD 381, PL 382, SA 380. No fixtures or venues were deleted and existing ticket links were preserved.

The local branch preview runs separately on port 3011. The configured database is shared with other checkouts; the venue-country fix in this branch must be merged and deployed before relying on an older checkout to label Welsh destinations correctly. No public deployment was performed.

Verification: 18 focused tests passed, including a route integration that persists Wales and omits England's flag, exact-roster failure cases and island DST/date boundaries; TypeScript passed. Live port-3011 draws returned HTTP 201 and persisted imported fixture results. A Welsh result was not captured by bounded random live sampling; Welsh geography is instead confirmed by seeded records and the deterministic route integration test. Preview home returned HTTP 200.
